# SwitchAndMerge
This MATLAB script was developed for analysis of phage-display peptide libraries sequenced using paired-end Illumina sequencing with mixed read orientation. 

In these libraries, the variable peptide-coding region is expected to be flanked by known constant sequences and fully covered by the overlap between the paired reads. The script performs forward-reverse orientation correction, quality control, and read merging. 

The resulting file is intented for downstream analysis with the PHASTpep software suite. Suggested modifications to the original suite are included.

Additional scripts for post-processing phage peptide library data are included. These scripts may search for and output motif families within a library, or remove given motif families. Another script vizualises the diversity profiles of peptide libraries.

# Quick start
1. Open PairedEnd_SwitchAndMerge.m
2. Change parameters in the section "Definition of variables" to include filepaths to the input files and the output folder and define output file name.
3. Optionally adjust run parameters in the same section, see parameters section below.
4. Run PairedEnd_SwitchAndMerge.m

The output fastq-file may be used as input for the PHASTpep suite. 

Certain updates to the PHASTpep code-suite is described in PHASTpep_compatibility. 

After having run the PHASTpep suite, the library data may be analyzed with the helper-scripts described in PostProcessingScripts

# Workflow overview
- Imports 2 fastq files with paired reads and checks that the headernames differ by 1 symbol exactly.
- Identifies read orientation from primer sequences and swaps forward and reverse reads where necessary.
    - An initial leniency of default 5 bp is allowed to account for miscalled bases in the beginning of the read
    - If the fwd primer is not located due to miscalled bases, the rev primer is used instead.
- Aligns the read pairs individually and locates the endflank sequence, which is a known constant sequence immediately downstream of the variable region and is used to verify correct library structure.
- Deletes any pairs where:
    - The aligment was unsuccessful
    - The endflank cannot be found (corresponding to WT contamination)
    - The endflank is found too early (corresponding to deletions of the peptide region or shortened fwd read) or too late (corresponding to too long variable region).
    - The overlap between the readpair does not cover the full variable region (corresponding to shortened rev read) 
    - Mismatches within the variable region (mismatches are tolerated outside the variable region).
- Merges the read-pairs to get the full amplicon length
- outputs a new fastq-file with the merged forward reads as well as a log showing amount of deleted read pairs for each quality control parameter.
 
# Input and output
Input: 
- Two FASTQ files containing corresponding read-pairs. Read orientation is determined from the specified primer sequences, allowing forward and reverse reads to be identified and corrected even if the input files contain a mixture of orientations, which is the case when illumina flanking primers have been added randomly to amplicons.
- Specifications: The user may specify forward and reverse primer sequences, endflank sequences and expected length of the variable region between endflank sequences.

Output: 
- A FASTQ file containing merged reads that pass all quality-control filters. Reads are discarded if they fail primer identification, endflank identification, expected variable-region length or contain mismatches in the variable region.
- A log file listing: Input files, steps passed, examples of switches forward and reverse reads for inspection, counts and percentage of deleted read pairs under each category (either due to misalignment, lack of endflank, too short variable region, mismatches within the variable region).

The output generated by this software is intended for use with the PHASTpep suite. This repository does not contain PHASTpep itself, but suggests modifications to the original code.

# Parameters

`File1`: Path to first input FASTQ

`File2`: Path to second input FASTQ

`Output_folder`: Path to output folder

`Output_fastq_name`: Name of output file

`Forward_prim_seq`: Sequence of forward primer for PCR amplicon: 'ATAAACCGATACAATTAAAGGCTCC' may be used for PhD-12
    
`Reverse_prim_seq`: Sequence of reverse primer for PCR amplicon: 'TTTTGTCGTCTTTCCAGACGTTAG' for PhD-12
    
`Initialerror`: Leniency for miscalled initial nucleotides: 5 default
    
`Overlap_endflank`: Sequence of flanking secuence at 3' end of variable region: 'GGTGG' for PhD-12
    
`Var_length`: Length of variable region: 36 for PhD-12; 21 for PhD-7
    
`Endflank_placement`: Endflank placement from start of amplicon: 148 with the above primer for for PhD-12
    
`Endflank_placement_leniency`: Leniency for miscalled initial nucleotides: 5 default

# Assumptions
- The variable region is fully contained within the overlap between paired-end reads.
- The sequence immediately following the variable region (the endflank) is constant and known.
- Reads originate from a library with a fixed variable-region length.

- Performance considerations: Large FASTQ files can require several hours to process, depending on dataset size and hardware. For large sequencing datasets, running the script on a dedicated compute server or shared computing resource may be preferable to using a local workstation.
